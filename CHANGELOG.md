# 0.2.0 – Local Task Exporter

- Replaces AI HTTP client UI with a local task exporter for OpenCode.
- New Preferences: General, Context & Export, editable Prompt Templates.
- Four configurable built-ins, unlimited custom templates, common instructions, variables.
- Preserves multi-object Object List selection and saved read-only context collector.
- Adds export versioning, unique folders, JSON provenance/limitations manifest, project-local OpenCode command.
- Supports attaching native DEF files produced by Developer Studio; auto DEF export not yet implemented.
- Adds pure Java end-to-end task export tests runnable without BMC libraries.
- Removes model/server/credential UI and unused HTTP client classes from source.
