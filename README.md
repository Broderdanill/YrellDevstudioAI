# Yrell AI Task Exporter 0.2.0 (first test version)

Developer Studio 26.1.1 (Java 17), plugin bundle `se.yrell.aiassistant`.

## What works

- Right-click multi-selection in BMC Object List: **Export with Yrell AI**.
- Dockable exporter view with selected saved Forms, Filters, Active Links, Escalations and Guides, when supported by the existing context collector.
- Editable **Preferences → Yrell AI Assistant → Prompt Templates** (common instructions + four built-in task templates + user templates).
- **Preferences → Yrell AI Assistant → Context & Export**: field/related filters, size limits, redaction, preview.
- **Preferences → Yrell AI Assistant**: local output root and optional OpenCode slash command.
- Exported folder includes `definitions/context.md`, `prompt.md`, `manifest.json`, `output/`, optional unchanged native .def files, and `.opencode/commands/yrell-task.md`.
- No HTTP, no server, no model/provider, no API keys. OpenCode handles model access independently.
- Job export always uses Preferences values at execution; templates are snapshotted into each `prompt.md`.

## Known first-version limitation

**The plugin does not yet perform native `.def` generation.** `context.md` is a structured, human-readable snapshot of saved definitions generated by the existing BMC object model collector. It is NOT a `.def` and cannot be used for BMC import. You can attach one or more `.def` files produced by Developer Studio's native Export wizard using **Add existing .def...**. They are copied byte-for-byte into `definitions/`. The manifest identifies whether native definitions are present and explicitly marks native auto-export as false.

Saved objects only; no unsaved editor changes, runtime records or guaranteed dependency closure. Related Active Links / Filters are best-effort. Redaction cannot guarantee complete removal of secrets. A .def attached manually is not redacted.

## Local build on workstation

From the unpacked project:

```bash
bash scripts/test-core.sh
bash scripts/build.sh "$HOME/Downloads/componentDeveloperStudioWindows.zip"
bash scripts/test.sh
```

If your BMC component ZIP is at a different location, pass that path. `scripts/build.sh` can reuse `./.build/devstudio/x64/plugins` from an earlier build. Built JAR: `install/se.yrell.aiassistant_0.2.0.jar`.

Or use `scripts/install-to-git.sh` with the release ZIP already saved under `~/Downloads`.

## Developer Studio install

Exit Developer Studio. Copy the built JAR into the appropriate installation `plugins/` folder, **removing the prior `se.yrell.aiassistant_0.1.0.jar`** first (do not leave two versions). Restart Developer Studio; if Eclipse caches an older bundle, clear the plugin cache using normal Eclipse configuration cleanup. The plugin can be found in **Window → Show View** and in Object List's context menu. 

## OpenCode

In the task directory generated by the plugin:

```bash
cd "/path/to/YrellAI/yrell-document-YYYYMMDD-HHmmss-SSS"
opencode
```

In the OpenCode TUI, type `/yrell-task`. This is a project-local command and uses your normal OpenCode provider/model. OpenCode will read `prompt.md` and definition files and save requested output into `output/`.

## Main sources

- `src/se/yrell/ai/bmc/ContextCollector.java`: read-only BMC context snapshot
- `src/se/yrell/ai/core/TaskTemplates.java`: editable prompt library
- `src/se/yrell/ai/core/TaskExporter.java`: local task output, command and manifest
- `src/se/yrell/ai/ui/AIView.java`: SWT task selection and export
- `src/se/yrell/ai/ui/PromptPreferencesPage.java`: editable prompt settings

## Unverified integration

The complete Eclipse/BMC bundle can only be compiled against local Developer Studio 26.1.1 libraries, which are not bundled here. Core export tests are run without the SDK. Test the object-menu action, Preferences pages and context snapshot inside your installed Developer Studio before using this in a sensitive environment.
